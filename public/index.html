Spreadsheet Formulas & Data Analysis (Class 10 IT Syllabus)

Formulas implemented in the spreadsheet module for automated grading

1. Total Present Days

=COUNTIF(D2:AB2, "Present") + 0.8*COUNTIF(D2:AB2, "Late")

Counts all present and weighted late arrivals for student row.

2. Attendance Percentage

=(Total_Present / Total_Working_Days) * 100

Computes mark-to-date turnout ratio formatted as percentage.

3. Defaulter Status Check

=IF(Attendance_Pct < 75, "DEFAULTER", "ELIGIBLE")

Conditional formula highlighting students barred from exams.

4. Class Turnout Average

=AVERAGE(AC2:AC21)

Aggregate section performance evaluation.
